# 🐰 备考兔 · 上岸工作台 · 奶油米色治愈系

一个清新可爱、治愈风格的 Web 备考工作台，PC 端和手机端都能流畅使用。
v2.0 全面升级为 **奶油米色（cream-beige）治愈系** 配色，新增兔子头像、每节课程笔记、
双栏时政、百分化练习、Word/PDF 导出、侧栏固定/折叠、字号设置、手势操作等。

## ✨ 核心特性

- 📱 **PC / 手机都能用**（响应式布局，侧栏在手机端可折叠 + 边缘手势操作）
- 💾 **数据本地保存**（所有数据写入浏览器 localStorage，不上传任何服务器，自动保存）
- 🎨 **奶油米色治愈系配色** `#f8f1e8` + 超大圆角 + 胶囊卡片 + 天蓝→薄荷渐变高亮
- 🐰 **可定制兔子头像** — 点头像上传图片，自动压缩到 300px 宽并保存
- 🏷️ **昵称 / 座右铭** 可在侧栏点击直接编辑（昵称最多 12 字）
- 📌 **侧栏固定/折叠** — 顶部 📌 钉住按钮切换「常驻固定」与「折叠收起」模式
- 🔤 **字号设置** — 侧栏底部小/中/大（14/16/18px），全局同步
- 🧩 **12 个功能模块**，覆盖公考 4 大类（核心功能 / 行测学习 / 申论学习 / 错题本）
- 🔄 **每日自动滚动内容**（按日期切换金句、时政、成语、题型、公式练习）
- 📚 **课程学习进度条**（言语 12 节 / 政治 9 节 / 常识 103 节 / 资料 28 节，可勾选打卡）
- 📝 **每节课程笔记** — 每节课程右下角 📝 按钮，可写文字 + 传图，任意时间再编辑
- 📰 **双栏时政** — 今日时政（5 条，注明日期）+ 往期时政（5 条 + 「换一批」刷新）
- 🧮 **百分化乱序练习** — 资料分析每日 10 道百分化/比重/增长率专项练习
- 🍅 **番茄钟** — 右下角浮动按钮，专注 25 分钟 + 休息 5 分钟自动切换
- 📊 **30 天学习曲线** — 统计模块自动生成可视化趋势图
- 📤 **错题导出** — 一键导出 Word（.doc）或 PDF，含分类 + 图片 + 备注 + 周汇总
- 🔄 **数据导入/导出**（一键备份你的复习数据）
- 🟢 **同步状态指示器** — 右上角显示「💾 保存中 / 🟢 已保存 / 连接状态」

## 🚀 快速开始

### 方式 1：直接双击 `index.html`

适合本机使用。所有数据保存在当前浏览器。

### 方式 2：用本地服务器（推荐，手机访问必备）

```bash
cd 上岸工作台
python3 -m http.server 8765
# 然后 PC 访问 http://localhost:8765/
# 手机访问 http://<你电脑的局域网IP>:8765/
```

> ⚠️ 由于浏览器安全策略，`file://` 协议下手机端可能无法访问，建议用 HTTP 服务器。
> 语音转文字（Web Speech API）需要 `https` 或 `localhost` 环境。

### 方式 3：一键体验示例数据

打开欢迎页后，点击 **"✨ 一键加载示例数据"** 按钮，会自动填充：
- 6 个每日打卡目标（其中 2 个已打卡）
- 近 30 天的做题统计（每天随机 0-3 条记录，覆盖所有模块）
- 5 道错题（覆盖本周 5 个模块）

也可在 URL 后加 `?demo=1` 参数直接加载：
- `http://localhost:8765/?demo=1#stats` — 进入带数据的统计页
- `http://localhost:8765/?demo=1&pomo=1` — 自动打开番茄钟面板
- `http://localhost:8765/?expand=1` — 课程目录默认展开（截图用）

## 🎛 个性化设置

### 兔子头像 / 昵称 / 座右铭
- 点击侧栏顶部头像 → 选择本地图片 → 自动压缩为 300px 宽 JPEG 并存入 localStorage
- 点击昵称 / 座右铭 → 弹窗编辑（昵称 ≤ 12 字），回车或确定即保存

### 侧栏固定 / 折叠（📌）
- 默认常驻固定（桌面 230px / 平板 170px / 手机 140px）
- 点击顶部 📌 钉住按钮 → 切换为「折叠收起」模式，偏好被记住
- 折叠模式下：左侧出现竖向「导航」条，点它或**从左边缘右滑**可呼出侧栏；**左滑 / 点击空白处**收起
- 固定模式不响应手势

### 字号（🔤）
- 侧栏底部「小 / 中 / 大」三档（14 / 16 / 18px）
- 通过 `body[data-font]` + CSS `em` 缩放实现，全站文字同步变化

### 同步指示器
- 每次自动保存时右上角显示「💾 保存中」，完成后显示「🟢 已保存」
- 直观反馈数据已落地到本地

## 💡 进阶用法

### 数据迁移（换电脑）
1. 在原浏览器左下角点击「💾 导出数据」，会下载一个 JSON 文件
2. 把 JSON 文件传到新电脑
3. 在新浏览器左下角点击「📥 导入数据」，选择该 JSON 即可

### 错题导出 Word / PDF
- 在错题本模块点击「📤 导出」，弹出选择框
- **导出 Word**：生成 `.doc` 文件，含分类、图片、备注、周汇总（用 Blob + msword 实现，离线可用）
- **导出 PDF**：调用浏览器打印预览，选择「另存为 PDF」即可（无错题时按钮自动禁用）

### 自定义每日内容
如果想覆盖某一天的时政/常识/成语等内容，可以直接编辑 `data.js` 中对应的数组。
浏览器端的"每日滚动"逻辑按 `dayOfYear(today())` + 种子随机（seededShuffle）从池中取数，
保证同一天内容稳定、跨天自动切换。

### 添加更多数据
- **时政热点**：在 `POLITICS_TODAY` / `POLITICS_PAST` 数组追加
- **毛选金句**：在 `MAO_QUOTES` 数组末尾追加 `{text, source}`
- **成语辨析**：在 `IDIOM_POOL` 数组末尾追加 `[ {word, meaning}, {word, meaning} ]`
- **逻辑题**：在 `LOGIC_POOL` 数组末尾追加 `{q, opts:[..4条], ans:索引, explain}`
- **数量关系题型**：在 `QUANTITY_POOL` 追加 `{type, formula, example}`
- **百分化练习**：在 `DA_PERCENT_POOL` 追加 `{q, opts:[..], ans:索引, explain}`

## 📝 数据存储说明

- 所有用户数据存储在浏览器 `localStorage`，键名 `shangan_workspace_v2`
- 头像、昵称、座右铭、课程进度、笔记、错题、统计、偏好（折叠/字号/往期偏移）均持久化
- 清除浏览器数据 / 切换浏览器 / 无痕模式下数据不会同步
- 建议每周导出一次作为备份

## 🛠 技术栈

- 纯 HTML / CSS / 原生 JavaScript，零依赖
- 单页应用（SPA），路由用 `location.hash`
- localStorage 数据持久化（防抖自动保存 + 同步状态指示）
- 响应式 CSS Grid + Flex + Media Queries（断点：1100px / 900px / 560px）
- Canvas 图片压缩（头像 300px）、Web Speech API（语音转文字）、Blob 导出（Word/PDF）
- 触摸手势（touchstart/touchend）实现折叠模式下的侧栏呼出/收起
